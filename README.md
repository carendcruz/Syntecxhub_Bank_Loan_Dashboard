# 📊 Bank Loan Dashboard

An interactive dashboard project built using Power BI and SQL to analyze bank loan data and generate meaningful business insights.

---

## 🚀 Features
- Loan approval and rejection analysis
- Funded vs received amount tracking
- Loan status analysis
- Interest rate insights
- KPI cards and filters
- Customer segmentation

---

## 🛠️ Technologies Used
- Microsoft SQL Server
- Power BI
- Excel

---


## 🎯 Learning Outcomes
- Data cleaning and transformation
- SQL querying
- Dashboard creation
- Financial data analysis
- Business intelligence reporting
